## 🚀 How to Run & Deploy
1. **Local Preview:** Just double-click `index.html` in your file explorer.
2. **GitHub Pages:**
   - Push repository to GitHub.
   - Go to `Settings` > `Pages`.
   - Set Source to `Deploy from a branch` -> `main` / `root`.
3. **Netlify or Vercel:** Drag and drop the folder into [Netlify Drop](https://app.netlify.com/drop).
